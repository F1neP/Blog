SM4 Block Cipher（SM4，SM4 分组密码算法）

BLOCK CIPHER · SM4

SM4（SM4 Block Cipher，SM4 分组密码算法）是 128 位分组、128 位密钥的 32 轮对称分组密码；加密与解密使用相同轮结构，解密只需把 32 个轮密钥逆序使用。

一、算法基本信息及特征

TYPESymmetric Block Cipher（对称分组密码）
BLOCK SIZE128 bit
KEY SIZE128 bit
ROUNDS32 轮
ROUND KEY32 × 32-bit words
STANDARDGB/T 32907-2016 现行

SM4 的每轮从四个 32 位状态字生成一个新字。非线性部分 τ 由四个并行 S-box 组成，线性扩散 L 使用多个循环左移与异或；密钥扩展复用同一 S-box，但采用不同线性变换 L′。

二、详细算法流程图

输入与拆分128 位 P 拆为 X₀、X₁、X₂、X₃；主密钥拆为 MK₀…MK₃
→
密钥扩展MK⊕FK 初始化，再用 T′ 与 CKᵢ 生成 rk₀…rk₃₁
→
轮输入异或Xᵢ₊₁⊕Xᵢ₊₂⊕Xᵢ₊₃⊕rkᵢ
→

→
反序输出32 轮后输出 X₃₅∥X₃₄∥X₃₃∥X₃₂

三、轮函数与密钥扩展

01
ROUND FUNCTION

由三个相邻状态字生成新状态字

02
NONLINEAR LAYER

逐字节查 S-box

把 32 位输入 A 拆成四个字节 a₀…a₃，分别经过同一 S-box，得到 B=τ(A)。这一层提供非线性。

03
LINEAR LAYER

循环移位并异或扩散

04
KEY SCHEDULE

生成 32 个轮密钥

K₀…K₃=MK₀…MK₃⊕FK₀…FK₃。解密不重新设计轮函数，只按 rk₃₁,…,rk₀ 的顺序执行。

五、安全边界与实际使用

  • SM4 只是分组置换：直接逐块加密不能自动隐藏重复模式，也不提供完整性。
  • 必须选择工作模式：工程中应依据标准使用 GCM、CCM 等具备认证能力的模式，并正确生成 Nonce（随机数/唯一数）。
  • 密钥与实现同样重要：需要安全随机数、密钥生命周期管理以及抗侧信道实现。
  • 协议绑定：算法标识、模式、IV/Nonce、标签长度及附加认证数据必须被协议明确固定。
一句话总结：SM4 用 32 轮“异或—S-box—线性扩散”处理 128 位分组，解密则沿用同一结构并逆序使用轮密钥。
