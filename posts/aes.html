Advanced Encryption Standard（AES，高级加密标准）

CLASSICAL CRYPTO · AES

AES（Advanced Encryption Standard，高级加密标准）是以 Rijndael 为基础的对称分组密码。它固定处理 128 位分组，并根据 128、192 或 256 位密钥执行 10、12 或 14 轮，是现代通用对称加密的核心算法。

一、算法基本信息及特征

TYPESymmetric Block Cipher（对称分组密码）
STRUCTURESubstitution–Permutation Network（替换—置换网络）
BLOCK SIZE固定 128 bit
KEY / ROUNDS128/192/256 bit；10/12/14 轮
STATE4 × 4 字节矩阵
STATUS当前广泛使用

AES 不采用 Feistel 左右分组，而是让整个 128 位 State（状态）反复经过非线性替换和线性扩散。SubBytes 提供非线性，ShiftRows 与 MixColumns 让一个字节的变化扩散到更多位置，AddRoundKey 把密钥材料注入状态。

二、详细算法流程图

输入与密钥扩展P 装入 4×4 字节状态；主密钥扩展为 Nr+1 个轮密钥
→
初始变换State ← State ⊕ RoundKey₀
→
中间 Nr−1 轮SubBytes → ShiftRows → MixColumns → AddRoundKey
→
最终第 Nr 轮SubBytes → ShiftRows → AddRoundKey，不做 MixColumns
→
输出密文按列读出 128 位 C；解密使用对应逆变换

三、AES 的具体步骤

01
KEY EXPANSION

扩展轮密钥

Key Expansion（密钥扩展）利用 RotWord、SubWord、轮常量 Rcon 与异或，从主密钥生成 Nr+1 组 128 位轮密钥。AES-128 因而需要 11 组轮密钥。

02
INITIAL ROUND

执行初始 AddRoundKey

状态矩阵与第 0 轮密钥逐比特异或。AES 中唯一直接使用密钥的运算就是 AddRoundKey。

03
MAIN ROUNDS

重复完整轮变换

SubBytes：每个字节经同一 S-box 非线性替换；ShiftRows：第 0–3 行分别循环左移 0–3 字节；MixColumns：每列在 GF(2⁸) 中乘固定可逆矩阵；最后执行 AddRoundKey。

04
FINAL ROUND

完成不含 MixColumns 的末轮

最后一轮只执行 SubBytes、ShiftRows 和 AddRoundKey。随后按列读出状态，形成 128 位密文。

疑问：AES-256 是否处理 256 位明文分组？

回答：不是。AES 的分组长度始终是 128 位；“128/192/256”指密钥长度，并分别决定 10/12/14 轮。

五、算法本身与使用模式必须一起考虑

  • AES 只加密单个分组：实际长消息必须使用工作模式，不能自行逐块调用。
  • 不要使用 ECB：相同明文块会产生相同密文块，泄露结构。
  • 优先使用 AEAD：AES-GCM 同时提供机密性与完整性，但同一密钥下 Nonce（随机数/唯一值）绝不能重复。
  • 实现安全同样重要：查表实现可能泄露缓存时序，应使用硬件指令或经过审计的恒定时间库。
一句话总结：AES 通过字节替换、行移位、列混合和轮密钥异或，在固定 128 位分组上反复实现非线性与扩散。
