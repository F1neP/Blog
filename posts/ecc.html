Elliptic Curve Cryptography（ECC，椭圆曲线密码学）

CLASSICAL CRYPTO · ECC

ECC（Elliptic Curve Cryptography，椭圆曲线密码学）不是单一的加密算法，而是一套在有限域椭圆曲线群上构造密码方案的方法。其核心运算是容易计算的 Scalar Multiplication（标量乘法）Q=dG，而逆向恢复 d 被称为椭圆曲线离散对数问题。

四、ECC 密钥生成步骤

01
DOMAIN PARAMETERS

使用标准曲线参数

参数通常写成 (p,a,b,G,n,h)：有限域、曲线系数、基点、基点阶与余因子。工程实现不应自行发明曲线或随意选择 G。

02
PRIVATE KEY

均匀采样私钥 d

从 1 到 n−1 均匀采样 d。随机源失败会直接导致私钥泄露。

03
PUBLIC KEY

计算 Q=dG

通过重复倍点与点加法计算 Q。公开 Q 和参数标识，保密 d。

04
VALIDATION

验证收到的公开点

根据协议检查编码、坐标范围、点是否在曲线上以及是否属于正确子群，防止无效曲线和小子群攻击。

六、ECC、ECDH、ECDSA 与 ECIES 的关系

名称完整英文名称主要目标
ECCElliptic Curve Cryptography曲线群上的公钥密码学总称，不是单一协议
ECDHElliptic Curve Diffie–Hellman协商共享秘密
ECDSAElliptic Curve Digital Signature Algorithm数字签名
ECIESElliptic Curve Integrated Encryption Scheme混合公钥加密框架
  • 方案不可混称：仅说“使用 ECC 加密”信息不足，必须说明曲线、协议、编码和 KDF/AEAD。
  • 签名随机数极敏感：ECDSA 的 nonce 重复、偏置或可预测会泄露私钥。
  • 验证输入点：错误的点验证可使私钥通过交互逐步泄露。
  • 量子边界：大规模容错量子计算机上的 Shor 算法会威胁 ECC 与 RSA；这与当前经典攻击强度是不同维度。
一句话总结：ECC 的核心是“容易计算 Q=dG、难以从 Q 恢复 d”，具体安全功能则由 ECDH、ECDSA、ECIES 等协议完成。
