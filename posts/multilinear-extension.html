Multilinear Extension：从 Boolean Table 到低度多项式

LEARNING NOTE · MULTILINEAR EXTENSION

Multilinear Extension（MLE，多线性扩展）解决一个在现代证明系统中反复出现的问题：我们手里往往只有一张定义在 Boolean Hypercube 上的离散 table，但 Sumcheck 等代数化验证工具需要低度多项式。MLE 在完全保留所有 Boolean 点取值的同时，把这张 table 唯一地延拓为有限域上的 multilinear polynomial。

MLE 的核心不是“压缩数据”，而是“给离散数据一个低度代数表示”：固定的是插值 basis，真正携带数据的是每个 basis 前面的 table value。

与本系列其他笔记的关系

Sumcheck 负责把 Boolean Hypercube 上的低度多项式大求和压缩到随机点检查；MLE 负责把原本没有代数结构的 Boolean table 转换成低度多项式；GKR 再利用 MLE 与 Sumcheck 逐层验证电路。可结合 Sumcheck Protocol 和 GKR Protocol 一起阅读。

二、什么是 Multilinear Extension？

Multilinear 的要求是：固定其他变量以后，多项式关于任意单个变量都是一次或常数：

MULTILINEAR1 + x₁ + 3x₂ + 5x₁x₂

每个变量自身最高只出现一次，因此是 multilinear。

NOT MULTILINEARx₁² + x₂

x₁ 的 individual degree 为 2，因此不是 multilinear。

CROSS TERMx₁x₂x₃

总次数可以大于 1；multilinear 并不要求 total degree 为 1。

为什么要这样构造？——把离散值“串”进一个多项式

可以把 MLE 的构造理解成一个插值问题：我们先要求每个 basis polynomial 在自己的 Boolean 位置 上取 1，在其他 Boolean 位置全部取 0。这个“只选中一个位置”的条件先确定了 basis 的作用；随后再把该位置真正的数据 乘上这个 selector。最后把所有位置相加：

七、为什么 MLE 是唯一的？

必须把“存在一个 polynomial extension”和“存在唯一的 multilinear extension”区分开。如果只要求在 Boolean points 上取值相同，那么 polynomial extension 并不唯一。例如 与 在 0 和 1 上取值相同；但后者不是 multilinear。加入 individual degree 至多为 1 的条件以后，MLE 就唯一。

唯一性的核心证明思路

假设两个 multilinear polynomials 在全部 Boolean points 上一致。取它们之差 ，则 在整个 Boolean Hypercube 上都为 0。只需证明这样的 multilinear 必须是零多项式。

一句话总结：Multilinear Extension 用固定的 Boolean Lagrange basis 把一张任意 Boolean table 唯一地写成低度多项式；basis 负责位置，table value 负责数据，而随机域点求值为 Sumcheck、GKR 等协议提供了可验证的代数接口。
