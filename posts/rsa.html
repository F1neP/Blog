Rivest–Shamir–Adleman（RSA，RSA 公钥密码算法）

CLASSICAL CRYPTO · RSA

RSA（Rivest–Shamir–Adleman，RSA 公钥密码）利用模幂运算构造一对方向相反的公钥与私钥操作。它可以作为加密或签名的数学基础，但两种用途必须采用不同、经过标准化的编码方案。

一、算法基本信息及特征

TYPEPublic-Key Primitive（公钥密码原语）
CORE OPERATION模 n 的大整数幂运算
PUBLIC KEY(n,e)
PRIVATE MATERIALd，通常还保存 p、q 与 CRT 参数
APPLICATIONRSA-OAEP 加密；RSA-PSS 签名
SECURITY BASISRSA/大整数分解相关困难问题

RSA 的公钥运算通常较快，私钥运算更昂贵；实现会利用 CRT（Chinese Remainder Theorem，中国剩余定理）分别模 p、q 计算以提速。安全性并不是“已证明完全等价于分解 n”，因此应准确地说 RSA 与大整数分解困难密切相关，并依赖具体方案的安全假设。

三、RSA 的具体步骤

01
KEYGEN

生成模数

随机生成两个不同的大素数 p、q，计算 n=pq 与 φ(n)=(p−1)(q−1)。真实实现必须使用密码学安全随机源并检测素数质量。

02
EXPONENTS

确定公私指数

选择满足 gcd(e,φ(n))=1 的 e，并计算其模逆 d=e⁻¹ mod φ(n)。公开 (n,e)，严格保护 d、p、q。

03
ENCRYPT

编码后执行公钥运算

先用 RSAES-OAEP 把消息与随机性编码成整数 EM，再计算 c=EMᵉ mod n。直接计算 mᵉ 的“裸 RSA”是确定性的，不是安全加密方案。

04
DECRYPT

执行私钥运算并验证编码

计算 EM=cᵈ mod n，再严格检查 OAEP 格式并恢复消息。实现还需要 Blinding（盲化）与统一错误处理以降低侧信道和填充预言机风险。

四、经典小参数数值例子

以下例子只演示裸模幂关系，不具备现实安全性：

  1. 选择 e=17，因为 gcd(17,3120)=1。
  2. 求模逆得到 d=2753，因为 17·2753=46801≡1 mod 3120。
  3. 公钥为 (n,e)=(3233,17)，私钥指数为 d=2753。
  4. 把教学消息写成整数 m=65，计算密文 c=65¹⁷ mod 3233=2790。
  5. 解密得到 m'=2790²⁷⁵³ mod 3233=65。

六、从数学原语到安全方案

疑问：把“加密公式反过来”是否就是 RSA 签名？

回答：不能这样实现。加密和签名虽然共享 RSA 模幂原语，但安全目标与编码不同：加密使用 RSAES-OAEP；现代签名优先使用 RSASSA-PSS。不能直接对原始消息做私钥幂。

  • 禁止裸 RSA：它是确定性的、具有代数结构，无法提供现代语义安全。
  • 密钥尺寸：现实系统通常至少使用 2048 位模数，并根据所需安全寿命选择更高强度。
  • 公钥加密长消息效率低：通常只封装随机对称密钥，再由 AES-GCM 等加密数据。
  • 抗侧信道：私钥运算应使用成熟库、盲化、CRT 校验和恒定时间实现。
一句话总结：RSA 用 ed≡1 mod φ(n) 构造互逆模幂，但现实安全来自“RSA 原语＋OAEP/PSS 编码＋安全实现”的完整方案。
