Private Set Intersection：只揭示集合交集

MPC APPLICATION · PRIVATE SET INTERSECTION

PSI 让参与方获得集合交集，而不公开非交集元素。严格设计首先要回答输出给谁、是否泄漏集合大小、元素是否去重、是否允许恶意方自适应查询；不同答案对应不同理想功能和不同协议。

为什么需要这一章？

普通加密只能隐藏集合内容，不能让双方在不解密全部元素的情况下找出交集。PSI 把“只泄漏交集及显式元信息”定义为独立功能，并可由 OPRF、OT 或多项式方法实现；本章用于区分交集计算与泛化的数据匹配。

形式化补充

二方 PSI 的基本功能可写为 FPSI(X,Y)=X∩Y\mathcal F_{\mathrm{PSI}}(X,Y)=X\cap YFPSI​(X,Y)=X∩Y，但必须说明结果给谁、是否保留 multiplicity、是否附带 payload、是否只输出基数 ∣X∩Y∣|X\cap Y|∣X∩Y∣。恶意安全还需约束一方是否能用重复/自适应元素进行成员测试，以及是否证明输入集合大小和元素格式合法。

一、PSI 不是唯一一个功能

可能只向一方输出交集、向双方输出、只输出基数 ，或附带 payload。集合大小、重复元素、排序、错误时机和谁先获得输出都属于安全定义的一部分。

二、元素编码必须确定且抗歧义

协议应使用域分离、长度前缀和规范化后的编码：

邮箱大小写、Unicode、电话号码国家码等应用规范化若不一致，会造成假阴性；若哈希到小域或截断过短，会产生假交集。Set 与 multiset 必须区分，重复项不能无意放大频率泄漏。

贯穿例子

A 持有 X={alice,bob,carol}X=\{alice,bob,carol\}X={alice,bob,carol}，B 持有 Y={bob,dave}Y=\{bob,dave\}Y={bob,dave}。双方先按同一规范（Unicode、大小写、长度前缀、域标签）编码元素。A 通过 OPRF 获得 Fk(x)F_k(x)Fk​(x) 而不知 key kkk；B 本地计算其元素 token 并发送经置乱的 token 集合。A 比较后只命中 bob。

若直接发送 H(x)H(x)H(x) 而元素来自邮箱/电话号码等低熵空间，A 或外部观察者可离线枚举字典。OPRF 的 key 隐藏使未参与协议者不能独立计算可比较 token，但仍需限制恶意在线查询。

三、OPRF 型 PSI 的直观接口

一方持有 OPRF key ，另一方对每个输入 获得 而不让 key holder 知道 ；key holder 本地计算自己集合的同类标签。比较伪随机标签得到交集。

01Encode规范化并哈希集合元素
02OPRF Evaluate隐藏 client 输入并绑定 server key
03Label Exchange发送排序/哈希后的伪随机标签
04Match只解码获准的交集与 payload

恶意安全 OPRF 需要证明 key 使用一致、群元素合法或通过标准 VOPRF 接口；简单的 DH 可交换构造不能忽略小子群和批量一致性检查。

四、OT-extension 型 PSI

OT-based PSI 常用 Cuckoo hashing 把一方元素放入 bins，再通过大量 OT/OPRF 对每个 bin 私下测试相等性。它主要使用对称密码，局域网中通常高效；但必须处理 stash failure、空桶编码、hash-function seeds 和恶意方构造冲突。

通用 garbled circuit/MPC 也能比较排序后的集合，且容易加入复杂 predicate 或 payload 逻辑；代价通常高于专用 PSI，但安全功能更灵活。

五、选择协议时比较什么

路线优势主要成本/假设
DH/OPRF结构清晰、通信线性、易扩展 payload公钥/OPRF 运算与群安全

六、输出本身可能成为查询接口

三条高风险路径
  • 小域枚举：攻击者用大量猜测元素加入自己的集合，通过交集结果测试成员资格。
  • 集合大小/重复泄漏：消息长度、bin 占用和输出重复次数泄漏业务敏感统计。
  • 恶意输入未绑定：同一方在不同子协议或重试中使用不同集合，破坏模拟安全结论。

部署时还需限制查询频率、最小集合/批次、认证对端与审计用途。密码协议保证一次执行的规定泄漏，不阻止攻击者从多轮合法输出做统计推断。

一句话总结：PSI 用 OPRF、OT 或通用 MPC 把元素转成可私下比较的标签；真正的安全边界由输出方、大小泄漏、恶意输入、编码和跨轮查询预算共同决定。

七、PSI 的泄漏、复杂度与选择边界

CORRECTNESS

交集正确性

相同语义元素应编码一致，不同元素的编码/哈希碰撞概率可忽略。

PRIVACY

非交集隐藏

除允许输出和大小等泄漏外，不应泄漏未命中元素；输出本身仍可能敏感。

MALICIOUS

输入控制

恶意方可批量试探成员关系、注入重复项或非规范编码，需按应用限制。

SCALABILITY

规模成本

OPRF、哈希表、OT extension、排序和网络传输的瓶颈随集合大小及失衡程度变化。
